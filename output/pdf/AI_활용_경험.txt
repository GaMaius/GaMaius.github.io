저는 AI 모델을 호출하는 데서 그치지 않고, 데이터 수집·분석·사용자 피드백을 연결해 실제로 사용할 수 있는 웹 서비스와 프로토타입을 만들어 왔습니다.

첫째, 리그 오브 레전드 전적을 보고도 무엇을 개선해야 할지 알기 어렵다는 문제를 해결하기 위해 Riot Report를 개발했습니다. Riot API의 경기·타임라인 데이터를 서버에서 지표로 계산하고, Gemini가 이를 근거로 강점·약점과 다음 경기의 훈련 과제를 제시하도록 구성했습니다. 결과물은 종합 코칭, 데스 분석, 라인전 분석, 구간 흐름·미션을 제공하는 AI 리포트 웹 서비스이며 Render에 배포했습니다. 저는 백엔드·프론트엔드와 AI 리포트 생성기를 설계·구현했습니다. 특히 AI가 근거 없는 숫자를 만들지 않도록 계산과 설명의 역할을 분리했습니다. 표본이 부족한 지표는 null로 전달하고 추정하지 않도록 지시했으며, JSON 출력을 사용해 화면에 연결했습니다. 이는 오류를 완전히 없애는 장치가 아니라, 데이터 부족과 출력 형식 문제를 통제하기 위한 설계입니다.

둘째, 웹캠 인식 결과를 사용자가 직접 체험할 수 있도록 VisionLab을 만들고 Vercel에 배포했습니다. MediaPipe·ONNX Runtime Web·three.js를 활용해 비전 분석과 3D 아바타 구동을 연결했습니다. 특히 VRM Capture에서는 얼굴·손·포즈의 추적 결과를 캐릭터의 움직임으로 변환했습니다. 모델 결과를 그대로 적용하면 손목이 비틀리거나 몸 일부가 화면에서 사라졌을 때 포즈가 멈추는 문제가 있어, 손목 회전 계산과 부위별 추적 신뢰도 처리를 보완했습니다. 또한 추론 실행 주기와 직전 결과 유지 로직을 분리해 프레임 처리와 움직임의 연속성을 다뤘습니다. 사전학습 모델을 직접 만든 것으로 표현하지 않고, 모델을 서비스에 연결하는 처리 흐름과 보정 로직을 구현한 경험입니다.

셋째, 팀 프로젝트에서는 AI를 사용자 행동으로 연결했습니다. 스마트 미러 웹앱에서는 MiniMax 기반 음성 비서와 타이머·일정 기능을 연결하는 작업을 맡았고, 기계 부품 학습 서비스에서는 3D 뷰어와 AI 학습 어시스턴트 구조 설계에 참여했습니다. 부품 정보와 질문을 함께 전달해 사용자가 보고 있는 대상에 맞는 설명을 제공하는 방식입니다. 초기에는 ResNet-18과 OpenCV를 활용한 수어 동작 이미지 분류 프로젝트에서 학습 시스템 개발을 담당하며, 데이터 준비부터 모델 출력 확인까지 경험했습니다.

이 과정에서 배운 것은 AI의 답변 자체보다 근거 데이터, 실행 가능한 기능, 확인 가능한 결과물이 중요하다는 점입니다. 새로운 문제에서도 AI에 맡길 판단과 코드로 검증할 처리를 나누고, 작동하는 결과물로 개선을 확인하겠습니다.
