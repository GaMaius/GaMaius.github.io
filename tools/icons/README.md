# 도트 아이콘 고치기 (Aseprite)

사이트의 아이콘은 모두 `img/px/<이름>.png` 이고, 크기는 **24×24px**, 배경은 투명입니다.
화면에는 24·48·72·96px처럼 24의 정수배로만 확대해서 보여 주므로, 24×24 안에서만 고치면 됩니다.

## 방법 1. 아이콘 하나만 고칠 때

1. Aseprite에서 `img/px/<이름>.png` 를 엽니다.
2. 고칩니다. 크기(Sprite > Canvas Size)는 바꾸지 마세요.
3. `Ctrl+S` 로 저장합니다. PNG 그대로 저장됩니다.

## 방법 2. 전체를 한 장에서 같이 고칠 때 (권장)

여러 아이콘의 색과 외곽선 두께를 나란히 보면서 맞출 수 있습니다.

```bash
python tools/icons/icons.py sheet
```

1. `tools/icons/icons-sheet.png` 가 만들어집니다 (가로 8칸, 한 칸 24×24).
2. Aseprite에서 열고 `View > Grid > Grid Settings` 를 **24×24** 로, `View > Show > Grid` 를 켭니다.
3. 칸 안에서만 고친 뒤 `Ctrl+S` 로 저장합니다. 칸 순서는 `order.txt` 를 따르니 아이콘 위치를 옮기지 마세요.
4. 다시 나눕니다.

```bash
python tools/icons/icons.py split
```

## 고칠 때 기준

이 아이콘 세트가 따르는 규칙입니다. 새로 그리거나 고칠 때도 맞춰 주세요.

- **외곽선**: 1px, 아이콘 색의 아주 어두운 버전 (순수 검정 아님). 끊긴 곳이 없게.
- **광원**: 왼쪽 위. 하이라이트는 1~2px만.
- **색**: 아이콘 하나에 서너 가지 색과 그 명암 정도. 그라데이션·디더링은 쓰지 않습니다.
- **여백**: 바깥 1px 정도는 비워 두고, 아이콘끼리 크기와 무게감을 비슷하게.
- **브러시**: 연필(Pencil) 도구만. 반투명 픽셀이 생기면 `split` 이 완전 투명/불투명으로 정리합니다.

## 고친 뒤

변경된 `img/px/*.png` 를 커밋하고 푸시하면 GitHub Pages에 반영됩니다.

```bash
git add img/px && git commit -m "icons: 아이콘 손질" && git push
```
